# Employee Salary Analysis — Financial Analytics & BI

A finance-oriented employee compensation analytics project built around `data/salaries.csv`. The repository turns salary, experience, age, degree, and qualification data into an analysis-ready workflow for payroll reporting, compensation diagnostics, workforce cost planning, and executive BI dashboards.

## Project objectives

This project is designed from a **financial analyst / FP&A perspective** rather than only as an exploratory notebook. It answers questions such as:

- What is the current annual payroll obligation?
- What are the mean, median, P10, P90, and salary quartiles?
- Which employee segments account for the largest payroll cost?
- How does compensation vary with experience, age, degree, and qualification?
- What would a 3%, 5%, or 8% salary increase cost?
- How concentrated is payroll in the highest salary quartile?
- Which observations sit materially above or below a simple analytical salary benchmark?
- How can the outputs be used directly in Power BI and Tableau?

## Pay-band framework

Employees are divided into salary quartiles:

- `Q1-Low`
- `Q2`
- `Q3`
- `Q4-High`

This allows an analyst to compare **headcount concentration** against **payroll concentration** and identify how much of total compensation expense sits in each quartile.

## Workforce segmentation

Where the relevant columns exist, the pipeline creates:

- Age bands
- Experience bands
- Degree-level summaries
- Qualification-level summaries
- Pay-band summaries

Each segment can be analyzed by:

- headcount
- average salary
- median salary
- total payroll
- minimum salary
- maximum salary

## Financial planning scenarios

The enriched dataset contains employee-level payroll scenarios for:

- 3% salary increase
- 5% salary increase
- 8% salary increase

For each scenario, the pipeline produces:

```text
scenario salary
incremental annual payroll cost
```

Because the calculation is done at row level, Power BI or Tableau can slice the incremental cost by degree, qualification, age band, experience band, or pay band.

## Salary benchmark model

A simple linear regression benchmark is fitted using the available fields among:

- experience
- age
- degree
- qualification

Categorical variables are one-hot encoded. The model exports:

- benchmark salary
- benchmark gap
- benchmark gap %
- MAE
- R²

This model is intended for **exploratory financial diagnostics and dataset interpretation**. It should not be used as an automated employment, promotion, termination, or individual compensation decision system.

## Financial analyst interpretation

The project separates five layers of analysis:

1. **Cost observation** — current payroll structure.
2. **Variance and distribution analysis** — spread, quartiles, percentiles, and cohort differences.
3. **Driver analysis** — association of salary with experience, age, education, and qualification.
4. **Scenario planning** — financial effect of broad compensation changes.
5. **Benchmark diagnostics** — comparison of actual salary with a simple statistical baseline.

See [`docs/FINANCIAL_ANALYSIS_FRAMEWORK.md`](docs/FINANCIAL_ANALYSIS_FRAMEWORK.md) for the complete analytical framework and data-quality checklist.
